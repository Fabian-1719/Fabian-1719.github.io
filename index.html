I'm a Computer Engineering student at the Instituto Tecnológico de Costa Rica. The trail so far

Five projects, from the most recent. Team projects say so; every figure comes from the code.

  1. RevisaTEC

    Team project · 3 people · Azure

    A peer code-review platform for university team projects. It connects to each team's repository, requires every change to be reviewed by a teammate before it merges, measures each student's real contribution and drafts feedback for the professor.

    • 3 microservices behind Azure API Management
    • Spring Boot with hexagonal architecture
    • Real-time notifications with Azure Web PubSub

    React · Spring Boot · FastAPI · Node.js · Azure

    Live site Code

  2. GameConsole + GameStats

    Team project · 2 people · 2 repos

    A multiplayer game console where you play against an AI written in Prolog. Matches run in real time over WebSockets, and every move is streamed to a separate analytics platform: a Go service validates the events and a Scala service turns them into player stats and patterns.

    • Minimax with alpha-beta pruning in Prolog
    • Event pipeline: TypeScript → Go → Scala
    • Docker images and CI on GitHub Actions

    TypeScript · Fastify · Prolog · Go · Scala · Docker

    GameConsole GameStats

  3. Ciudad Pastel

    Team project · 4 people · top contributor

    A web platform for a pastry business that combines an online store and a baking academy with courses and enrollments. A monorepo with a React web app and a REST API documented with Swagger.

    • Store, cart and course enrollments in one app
    • Express API on Firebase, tested with Vitest

    React · Express · Firebase · Vitest

    Private repository

  4. NEXUS ARCA

    Team project · web scraping

    A video game price tracker. It scrapes digital and console stores, collects release dates, genres and covers, and serves everything through a REST API that refreshes itself every 24 hours.

    • 20+ stores scraped
    • 80 concurrent workers: processes, threads and async I/O
    • Firebase sync with a local JSON fallback

    Python · Flask · asyncio · Firebase · JavaScript

    Live site Code

  5. Space Invaders

    Solo project · Python

    An arcade shooter in the style of the classic, built with Pygame: power-ups, a mystery ship, player profiles, match history and a top-5 leaderboard saved between sessions.

    Python · Pygame
